## 🎯 Project Overview
This portfolio showcases modern front-end web development, featuring:
- **Interactive Animations**: Powered by GSAP & ScrollTrigger.
- **Smooth Scrolling**: Implemented using Lenis for an immersive UI experience.
- **Responsive Layout**: Designed to adapt seamlessly across desktop and mobile devices.
- **Modern Development Workflow**: Built with Vite for rapid bundling and hot module replacement.

---

## ✨ Features
- **Smooth Page Transitions**: GSAP-driven transitions for smooth navigation.
- **Dynamic Hero Section**: Interactive image sequencing and typography.
- **Featured Projects Showcase**: Highlighted work items with interactive hover cards.
- **Contact Form**: Direct contact integration.

## 🚀 Installation & Setup

### Prerequisites
- [Node.js](https://nodejs.org/) (v16 or higher)
- npm or yarn

### Steps to Run Locally
1. **Clone the repository:**
   ```bash
   git clone https://github.com/Ratnawat-01/codingenthusiastofficial.git
   ```

2. **Navigate to project directory:**
   ```bash
   cd codingenthusiastofficial
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start local development server:**
   ```bash
   npm run dev
   ```

5. **Build for production:**
   ```bash
   npm run build
   ```
